# Quant Markets

Piattaforma di analisi quantitativa: costruzione e confronto di portafogli, analisi dei mercati
(eccessi, drawdown, tassi, materie prime) ed educazione finanziaria per i clienti.

* Sito: https://giovannilamattina971.github.io/quant-markets/
* I dati si aggiornano da soli ogni notte (martedì–sabato, dopo la chiusura USA) con `tools/update.py`,
  eseguito da GitHub Actions (`.github/workflows/update.yml`).
* Esito dell'ultimo aggiornamento: `data/update_log.json` e la pagina «Info dati» del sito.
* Aggiornamento manuale: scheda *Actions* → *Aggiorna dati e pubblica* → *Run workflow*.

I portafogli e il nome del cliente restano nel browser di chi usa il sito: non vengono mai salvati qui.
